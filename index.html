⚙ Connect Bot Server
1
Start the server on your PC/Mac
Open terminal in your bot folder and run:
node server.js TAP TO COPY
The server starts on port 4000 and automatically launches a Cloudflare tunnel.
After ~5 seconds your terminal will print the URLs.
✅ No extra install needed — tunnel starts automatically
2
Connect this dashboard
Copy the WS URL from your terminal output:
wss://xxxx.trycloudflare.com/ws
Paste it here and tap Connect:
3
Set TradingView Webhook URL
Copy the Webhook URL from your terminal and paste in:
TradingView → Alert → Notifications → ☑ Webhook URL
Format:
https://xxxx.trycloudflare.com/webhook?secret=sui_smc_2024
⚠ TradingView requires HTTPS (port 443) — the tunnel provides this automatically
4
Add Pine Script to TradingView chart
Open SUI/USDT 5M chart in TradingView →
Pine Editor → paste SUI_SMC_Bot.pine → Add to chart →
Create alerts for each alertcondition (8 total)
Use the same Webhook URL for all alerts.
